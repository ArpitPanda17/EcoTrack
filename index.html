PROJECT INFORMATION

About EcoTrack

A simple Data Science project for understanding household water consumption.

THE PROBLEM

Where is household water being used?

Water is consumed through many everyday household activities, but people may not know how much they are using in total or which activity contributes the largest share.

THE SOLUTION

Turn everyday usage into understandable data.

EcoTrack collects household usage information, processes it using R, calculates estimated consumption and presents the results using statistics, charts and simple insights.

TECHNOLOGY USED
HTML Page structure
CSS Visual design
JavaScript Interaction
R Data analysis
Plumber Frontend ↔ R connection
CSV Historical data storage
PROJECT LIMITATION

This is an estimation system.

EcoTrack does not physically measure water flow. It estimates usage using user-entered information and project assumptions. Therefore, its results are intended for educational analysis and awareness.
